# ТЗ-21. Меню привязок (constraints) как во Fusion + иконки привязок, которые можно удалить

## Цель (пользователь)
Два режима привязок:
1. Быстрые автоматические подсвечиваемые привязки при рисовании — УЖЕ есть (ТЗ-19/20), не трогать.
2. Меню привязок как во Fusion (панель CONSTRAINTS) — полноценная операция: нажал инструмент → тапнул
   первый объект → тапнул второй → привязка создана. Для начала 5 инструментов:
   **Касательность, Параллельность, Перпендикулярность (90°), Фиксация (замочек), G2 (для сплайнов)**.
Плюс на геометрии рисуются ИКОНКИ существующих привязок; тап по иконке выделяет привязку, кнопка Delete в
нижней панели её удаляет («иконки привязок, на которые можно было бы нажать и удалить привязку»).

## Сделать
### 1. Меню привязок в touch-рейле
В `Toolbar.cpp` (touch-ветка) после Dimension — кнопка **Constraints** (иконку подбери из имеющихся
`MZ_ICON_*`). Тап по ней открывает поп-ап (`ImGui::OpenPopup`/`BeginPopup`) с 5 крупными кнопками
(высота ≥ 44 dp через `materializr::uiScale()`): Tangent, Parallel, Perpendicular, Fix, G2. Выбор кнопки
активирует режим «Constrain» с этим типом (новое значение `m_activeSketchMode`, например 20, и поле с
выбранным `ConstraintType`; кнопка Constraints в рейле подсвечена как активная, на ней подпись выбранного
типа). Повторный тап по активной кнопке инструмента / выбор другого инструмента — выход из режима.
### 2. Операция «тап — тап»
В режиме Constrain (обработка тапа там же, где сейчас Select-тап в `Application_Viewport.cpp`):
- тап → `pickSketchAt` → объект (линия/окружность/дуга/сплайн/точка) подсвечивается как выделенный;
- Fix — достаточно одного тапа: точка → `Fixed` на точку; линия → `Fixed` на оба конца; окружность/дуга →
  на центр (и концы дуги); сплайн → на все его точки. Сразу применить;
- остальные — второй тап по другому объекту → применить; затем выделение сбрасывается, режим остаётся
  (можно сразу ставить следующую), как во Fusion;
- допустимые пары: Parallel / Perpendicular — линия+линия; Tangent — линия+окружность/дуга (как сейчас),
  а также сплайн + (линия/окружность/дуга/сплайн); G2 — сплайн + (линия/окружность/дуга/сплайн).
  Для пар со сплайном: `entityA = id сплайна`, `entityB = id второго объекта` (если сплайнов два — первый
  тапнутый = entityA). Математику сплайнов делает ТЗ-22 (параллельно), здесь только создание привязки;
- недопустимая пара — короткое сообщение в статусе (как другие статусы приложения; найди существующий
  механизм тостов/статуса), выделение сбрасывается до первого объекта;
- применение — новой функцией `Application::addSketchConstraintPair(ConstraintType t, int a, int b)`
  (b = -1 для одноэлементных) внутри `recordSketchMutation` + прогон солвера так же, как это делает
  `applySketchConstraint` (посмотри, что он вызывает после добавления). Не дублируй логику — можно вынести
  общую часть.
### 3. Иконки привязок на геометрии
Рисовать в экранных координатах через `ImGui::GetBackgroundDrawList()` (или тот draw list, которым рисуются
подписи размеров в скетче — найди, как рисуются лейблы Distance/Radius, и используй тот же переход
скетч→экран). Только в режиме редактирования скетча.
- Для типов: Horizontal (H), Vertical (V), Parallel (//), Perpendicular (⊥ — нарисовать линиями), Fixed
  (замок — прямоугольник + дуга), Tangent (круг + касательная линия), G2 (текст «G2»), Coincident
  (маленький квадрат), Equal (=), Concentric (два круга). Размеры (Distance/Radius/Angle/DistancePointLine/
  CircleGap) НЕ рисовать — у них свои подписи.
- Иконка — плашка 22 dp (скруглённый квадрат, тёмный фон, светлый значок; неудовлетворённая — красная
  обводка). Позиция: у объекта (середина линии, точка на окружности под 45°, точка у конца сплайна, у точки —
  сама точка) со смещением 16 dp; если у объекта несколько иконок — ряд вдоль, шаг 24 dp. Привязка с двумя
  объектами — иконка у каждого.
- Тап по иконке (радиус 16 dp, приоритет выше, чем пик геометрии) в режиме Select или Constrain → эта
  привязка становится «выделенной привязкой» (`m_selectedConstraintId`), иконка подсвечена акцентом,
  выделение геометрии сбрасывается. Тап в пустоту — сброс.
- Нижняя панель: при выделенной привязке кнопка Delete удаляет её (`Sketch::removeConstraint`) одним шагом
  undo через `recordSketchMutation`, затем солвер.
- В touch отключи старые GL-глифы H/V/Parallel/Perpendicular в `SketchRenderer.cpp` (под `touchMode()`), чтобы
  не дублировались.

## Критерии приёмки (планшет)
- Constraints → Parallel → тап линия, тап линия → линии параллельны, на обеих иконка «//».
- Fix → тап сплайн → у его точек замки; точки не тянутся.
- Tangent: линия + окружность работает; сплайн + окружность создаёт привязку (её поведение — ТЗ-22).
- Тап по иконке → подсветка → Delete → привязка удалена; «Назад» её возвращает.
