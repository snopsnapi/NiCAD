# ТЗ-15 (v2). Точки скетча: сначала выделить (тапом или рамкой), потом двигать — как во Fusion

## Цель (пользователь)
«Точки должны выделяться выделением как во Fusion: выделил — они стали доступны для перемещения».
«Тап тоже оставь» — «2 типа выделения». То есть в touch:
1. **Выделение тапом**: тап по точке скетча выделяет её (подсветка). Тап по уже выделенной — снимает
   выделение (или с включённым «Multi» — добавляет/снимает; найди, как «Multi» передаётся — `io.KeyCtrl`/
   `addToSel` в `onMouseDown`).
2. **Выделение рамкой**: существующее рамочное выделение элементов скетча (`m_sketchBoxSelectActive`,
   `src/app/Application_Viewport.cpp` ~6970–7080, выбирает точки/линии/дуги/сплайны в прямоугольнике) — выясни, как
   оно запускается на планшете в режиме скетча (долгое нажатие `Window::isTouchHoldSelect()`? протяжка по пустому
   месту в Select?) и сделай, чтобы работало в инструменте Select: долгое нажатие на ПУСТОМ месте + протяжка = рамка.
   **Два типа рамки, как во Fusion** (пользователь: «слева направо и справа налево разное выделение»;
   и «рамочное выделение не выделяет точки отдельно»). Направление — по X от точки начала к точке конца протяжки:
   - **слева направо (окно, window)**: выделяются точки внутри прямоугольника и ТОЛЬКО те элементы (линии,
     окружности, дуги, сплайны), которые ЦЕЛИКОМ внутри (все их точки/сэмплы внутри). Элементы, которые рамка лишь
     пересекает, НЕ выделяются → так можно выделить отдельные точки и двигать только их;
   - **справа налево (пересечение, crossing)**: как сейчас — точки внутри + все элементы, которые рамку задевают.
   Код — отпускание рамки в `Application_Viewport.cpp` ~7005–7080 (`selPts`, `selLns`, `selCircs`, `selArcs`,
   `selSpls`; для кривых уже есть `anySampleInRect` — добавь `allSamplesInRect` для окна; для линии — оба конца
   внутри). Направление брать из исходных точек протяжки, а не из `getMin()/getMax()` (проверь, хранит ли `BoxSelect`
   стартовую точку; если нет — добавь геттер). Визуально, как во Fusion: окно — сплошная рамка, пересечение —
   пунктирная (если BoxSelect::render легко поддерживает стиль; если нет — цветом: синяя / зелёная). Применять и на
   десктопе, и на планшете (это поведение Fusion, пользователь его ждёт везде).
3. **Перемещение**: протяжка, начатая на ВЫДЕЛЕННОЙ точке, двигает все выделенные точки (существующий код
   переноса в `SketchTool::onMouseMove`, `m_dragPointId`/`m_isDragging`, `movePoint`, `slideOrRelease`), один шаг Undo.
   Протяжка, начатая на НЕвыделенной точке, точку НЕ двигает (в Select — ничего не происходит или рамка, если это
   долгое нажатие; камеру при этом не вращать — как сейчас при тапе по элементу).
Десктоп (мышь) не менять.

Ранее (v1) обсуждалось удержание 1 с — ОТМЕНЕНО, не делать.

## Сейчас
`SketchTool::handleSelectTool` (~2440–2470): при нажатии на точку она сразу добавляется в выделение И начинается
перенос (`m_dragPointId = nearPt; m_isDragging = true;`). Повторное нажатие на выделенный элемент тянет всё выделение
(`reclickedSelected`). Нужно в touch: нажатие на НЕвыделенную точку — только выделить (без `m_isDragging`);
нажатие на выделенную — начать перенос (как сейчас), а если отпустили без движения — снять выделение с неё.

## Инструмент Spline (touch)
- Тап по первой точке незаконченного сплайна при ≥3 точках — замкнуть (как сейчас); по последней — завершить.
- Тап по любой другой существующей точке сплайна (средней точке незаконченного или точке готового сплайна) —
  ВЫДЕЛИТЬ её, а не ставить новую точку (сейчас добавляет её повторно в сплайн).
- Протяжка, начатая на выделенной точке, — перенос (как в Select), сплайн перерисовывается. После отпускания
  инструмент Spline продолжает работу (следующий тап в пустом месте — следующая точка).
- Протяжка от невыделенной точки или с пустого места — поведение инструмента как сейчас.
Для этого инструменту Spline нужно видеть набор выделенных точек `m_selectedPoints` — это общий член SketchTool,
используй его.

## Undo
Найди, как Select пишет Undo для переноса (`recordSketchMutation` вокруг `onMouseDown` в
`Application_Viewport.cpp` ~6960 и/или на отпускании) и сделай так же в Spline — перенос = один шаг; свайп «Назад»
его откатывает.

## Критерии приёмки (куратор/пользователь, планшет)
1. Select: тап по точке — выделена; протянуть её — двигается; протянуть невыделенную — не двигается.
2. Select: долгое нажатие на пустом + протяжка — рамка выделяет точки; протянуть одну из выделенных — едут все.
3. Spline: тап по средней точке — выделяется, новая не ставится; протянуть её — двигается; затем тап в пустом —
   сплайн продолжается.
4. Замыкание по первой и завершение по последней — как раньше.
