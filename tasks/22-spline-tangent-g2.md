# ТЗ-22. Касательность и G2 сплайна к другим кривым (сплайн «пристёгивается» к кругу/линии/сплайну)

## Цель (пользователь)
«Я не могу привязать сплайн к кругу, так как привязываются только точки». Нужны привязки КРИВАЯ–КРИВАЯ:
- **Tangent**: конец сплайна лежит на другой кривой и касается её (G1);
- **G2**: то же + совпадает кривизна (непрерывность по кривизне, как во Fusion/Alias).
Другая кривая: линия, окружность, дуга или другой сплайн. Сплайн подстраивается, другая кривая — опорная
(не двигается).

## Модель
Привязка `Constraint{type = Tangent или G2, entityA = id сплайна, entityB = id другой кривой}` (создаёт её
ТЗ-21 из меню; ты можешь проверять через тест). Тип объекта по id определяется перебором
`getLines/getCircles/getArcs/getSplines` (id уникальны между типами). `ConstraintType::G2` уже добавлен в
`SketchConstraints.h`.

Сплайн в скетче — интерполяционный через `controlPointIds` (`Sketch::sampleSpline2D`,
`Sketch::interpolate2D`, `exactSplineInterpolant` в `Sketch.cpp` ~687–830; точная геометрия для выдавливания —
`Sketch.cpp` ~1564). Интерполяция поддерживает условия на производные в точках:
`fitspline::interpolate(points, constraints{index, d1, optional d2}, degree, out)` (`FitSpline.h`).

## Сделать
### 1. Какой конец «пристёгнут»
Для привязки сплайн S ↔ кривая C: конец S (первая или последняя точка, только открытый сплайн) —
тот, что ближе к C. Если замкнутый сплайн — привязка не применяется (`isSatisfied = false`).
### 2. Пост-проход после солвера: `void Sketch::enforceSplineContacts()`
Вызывать в конце `SketchSolver::solve(Sketch&, ...)` (SketchSolver.cpp:27), на каждом выходе из функции, и
после загрузки проекта (найди, где после загрузки зовётся solve — если зовётся, достаточно этого).
Для каждой привязки Tangent/G2 со сплайном в entityA:
- выбранная концевая точка проецируется на C: линия — на бесконечную прямую (или отрезок с продолжением),
  окружность/дуга — на окружность (точка = центр + R·норм(p−центр)), сплайн — ближайшая точка по
  `sampleSpline2D` (плотная выборка + уточнение по соседним сегментам достаточно). Если эта точка скетча
  `Fixed` или общая с C (её id — конец линии/дуги/сплайна C) — не двигать, только проверить.
- `isSatisfied` = расстояние до C < 1e-4 мм.
### 3. Условия на конец сплайна при построении кривой
Новое: `struct SplineEndCondition { bool active=false; glm::dvec2 dir; double curvature=0; bool g2=false;
glm::dvec2 normal; };` и функция `Sketch::splineEndConditions(const SketchSpline&, SplineEndCondition& start,
SplineEndCondition& end) const` — вычисляет из привязок:
- dir = единичная касательная C в точке контакта: линия — направление линии; окружность/дуга —
  перпендикуляр к радиусу; сплайн — производная по выборке (или по OCCT-кривой этого сплайна, если её
  удобно получить). Знак выбирается так, чтобы dir смотрел в ту же сторону, что касательная самого сплайна
  на этом конце БЕЗ условий (скалярное произведение > 0; для начала сплайна — касательная «внутрь» сплайна).
- G2: curvature = кривизна C (линия 0, окружность 1/R, сплайн — по второй производной), normal — к центру
  кривизны.
- Если C — сплайн с привязкой обратно к S, для C брать его форму без условий (не рекурсировать).
Передача в интерполяцию: параметры fitspline нормированы в [0,1] по длине хорды, поэтому
`d1 = dir * L`, где L — сумма длин хорд между точками сплайна; для G2 `d2 = curvature * L² * normal`.
Протяни условия через `sampleSpline2D` → `interpolate2D` (новые необязательные параметры в конце, значения
по умолчанию — без условий, чтобы все старые вызовы не менялись) → `exactSplineInterpolant` (ключ кэша
должен включать условия!) и в построение точной геометрии ~1564, чтобы выдавливание совпадало с экраном.
При активных условиях используй `fitspline::interpolate` + `fitspline::toOcct` (а не GeomAPI_Interpolate —
у него свои параметры), для > 40 точек — тоже fitspline (условия только на концах; если медленно — отметь
в отчёте).
### 4. Солвер
В `SketchSolver.cpp` привязки Tangent/G2, где entityA — сплайн: 0 уравнений в подсчёте (`numEquations`),
ошибка 0 в `computeError`, без коррекции в `applyCorrection` (их делает пост-проход). Существующий Tangent
линия↔дуга не трогать. Добавь `case ConstraintType::G2` в switch'и (сейчас его там нет).
### 5. Тест `tests/test_spline_tangent.cpp` (+ регистрация как `test_sketch_merge`)
- окружность R=10 в (0,0); открытый сплайн из 4 точек, последняя ≈ (10.5, 3); Tangent(сплайн, окружность) →
  после `enforceSplineContacts` последняя точка на окружности (|p| = 10 ± 1e-6); касательная сплайна на конце
  (по `sampleSpline2D`, два последних сэмпла) перпендикулярна радиусу (|cos| < 1e-2).
- то же с G2: дополнительно кривизна сплайна на конце ≈ 0.1 (оценка по трём последним сэмплам, допуск 10%).
- линия (0,0)-(20,0), сплайн с концом около (5, 0.5), Tangent → конец на линии, касательная горизонтальна.
