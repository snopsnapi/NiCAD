# ТЗ-11. Сплайн скетча на новой математике (FitSpline) + удобный инструмент на планшете

## Цель (BACKLOG пп. 2, 2a, 3)
1. Сплайн скетча строится не центростремительным Catmull-Rom (только G1, кривизна скачет), а кубическим
   C2-сплайном через точки — `materializr::fitspline` (src/modeling/FitSpline.h, уже протестирован в CI против
   Python-эталона Nikaishi). Совместимость со старыми проектами НЕ нужна (решение пользователя).
2. В геометрию (экструд и т.д.) целая кривая идёт ТОЧНЫМ B-сплайном, без пересэмплирования и
   `GeomAPI_PointsToBSpline`.
3. На планшете: после постановки точки НЕ показывать жёлтый «следующий» сегмент к курсору; при ≥3 точках
   первая точка подсвечивается кольцом и ловится пальцем с увеличенным радиусом — тап по ней замыкает сплайн;
   привязки-подсказки (перпендикуляр/параллель к предыдущему отрезку) для сплайна отключены.

## 1. Математика — `src/modeling/Sketch.cpp`
`Sketch::interpolate2D(ctrl, segsPerSpan, closed, spanStartIdx)` (~строка 635) — сейчас Catmull-Rom через
`catmullRomPoint`. Замени ВНУТРЕННОСТЬ, сохранив сигнатуру и контракт (её зовут ~20 мест: рендер, снап, трим,
оффсет, экспорт SVG/DXF — см. `grep -rn "sampleSpline2D\|interpolate2D" src`):
- open: `fitspline::interpolate(points3d(z=0), {}, 3, curve)`; точки входа = контрольные точки сплайна;
  если вернул false (совпадающие точки) — откат на прямые отрезки между точками.
- closed (`closed=true`, n ≥ 3): периодическая кубическая интерполяция. Нужны ИЗВЕСТНЫЕ параметры точек
  (для разбиения на пролёты). Используй `GeomAPI_Interpolate` с явным массивом параметров (хордовая
  параметризация, как в `fitspline`) и `periodic = true` — найди конструктор с `Parameters` в заголовке OCCT /
  примере `src/modeling/LoftOp.cpp:142`; если такого конструктора нет — сделай periodic через `interpolateClosed`
  и параметры точек получи проекцией (`GeomAPI_ProjectPointOnCurve`). Опиши выбор в отчёте.
- Сэмплирование: каждый пролёт i (между params[i] и params[i+1]) делится как сейчас: число сегментов =
  clamp(ceil(длина_хорды/kTargetSegMm), segsPerSpan, kMaxSegsPerSpan); `spanStartIdx` заполняется так же; последняя
  точка (или первая для closed) — точно контрольная. То есть все вызывающие получают тот же формат.
- `catmullRomPoint` удали (или оставь неиспользуемым только если иначе ломается сборка — тогда напиши).

## 2. Точная геометрия — тот же файл
Места, где для сплайна делается `GeomAPI_PointsToBSpline fit(arr, degMin, 8, GeomAbs_C2, 1.0e-3)` (~1406 и ~2230):
- для ЦЕЛОГО сплайна (не sub-edge) — строй кривую точно: открытый — `fitspline::interpolate` по 2D-точкам, затем
  перенеси полюса в мир (`sketchToWorld` для каждого полюса — аффинное отображение сохраняет B-сплайн) и
  `fitspline::toOcct`; закрытый — та же периодическая кривая из п.1, но по мировым точкам. Ориентация
  (`fromPt == es.endPtId` → реверс) — `curve->Reversed()` / `BRepBuilderAPI_MakeEdge` + `Reversed()`; проверь, как
  сейчас работает реверс сэмплов, и сделай эквивалентно;
- для sub-edge (кусок сплайна между точками, легшими на него) — оставь существующий путь через сэмплы+fit.

## 3. Инструмент — `src/modeling/SketchTool.cpp`, `src/viewport/SketchRenderer.cpp`
- `SketchRenderer.cpp` ~809, ветка `mode == SketchToolMode::Spline` (жёлтое превью «точки + курсор»): при
  `materializr::touchMode()` рисуй превью только по УЖЕ поставленным точкам (без `ctrl.push_back(end)`); десктоп — как было.
- Там же: при `tool->splinePointsInProgress().size() >= 3` рисуй вокруг первой точки кольцо (окружность ~18 dp
  экранного радиуса, переведи через масштаб пикселя скетча — посмотри, как рендер рисует маркеры точек и как
  `SketchTool` знает `pixelScale`), цвет — тот же жёлтый.
- `SketchTool.cpp` `handleSplineTool` (~2917): замыкание срабатывает только при точном попадании в существующую точку
  после `snap()`. В touch при ≥3 точках: если позиция ближе к первой точке, чем 24 dp (в мм через pixelScale),
  считать `ptId = m_splinePoints.front()`.
- Подсказки-направляющие для сплайна: в конце `handleSplineTool` задаётся «направление предыдущего отрезка» для
  перпендикуляр/параллель-гайдов, и в `snap()` (~1234) есть ветка `m_mode == SketchToolMode::Spline` для симметрии.
  В touch для режима Spline отключи эти гайды (привязка к существующим точкам и сетке остаётся).
