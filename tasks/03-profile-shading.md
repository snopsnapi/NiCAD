# ТЗ-03. Лёгкая заливка всех замкнутых контуров скетча (как во Fusion)

## Цель
Сейчас замкнутый контур скетча заливается только когда он выбран/под курсором. Во Fusion все замкнутые
профили видимых скетчей слегка подсвечены всегда — сразу видно, что контур замкнулся и его можно тянуть.
Сделать так же: бледная полупрозрачная заливка всех «нарисованных» регионов всех видимых скетчей и
активного скетча.

## Где
Один файл: `src/app/Application_Viewport.cpp`, плюс одно поле в `src/app/Application.h`.

Образец — блок «Cosmetic region fills (Fill tool)» (~строки 1116–1140): лямбда `drawFills`,
`regionsCached()` / `m_regionWorker->ensure(sk)`, `buildRegions()` (cache hit), сбор `TopoDS_Face`,
один вызов `m_sketchRenderer->renderFacesFill(...)`, цикл по `getAllSketchIds()` + активный скетч.

## Что сделать
1. В `Application.h` рядом с другими флагами отображения добавь
   `bool m_shadeProfiles = true;  // light fill of every closed sketch profile (Fusion-style)`.
2. В `Application_Viewport.cpp` ПЕРЕД блоком Fill tool добавь такой же блок «Profile shading»:
   - работает только при `m_shadeProfiles`;
   - цвет `glm::vec3(0.95f, 0.60f, 0.20f)` (тёплый, как профили во Fusion), альфа `0.12f`;
   - для каждого скетча: если `!sk.regionsCached()` и `!(m_regionWorker && m_regionWorker->ensure(sk))` → пропустить
     (никогда не строить регионы на главном потоке);
   - **для активного скетча в режиме скетча** дополнительно пропускать, пока идёт размещение фигуры:
     `m_sketchTool && m_sketchTool->isPlacing()` (иначе каждый сдвиг точки перезапускает фоновую сборку);
   - регионы: `const auto regions = sk.buildRegions();` индексы — `sk.drawnRegions(regions)` (только
     нарисованные пользователем, без остатка грани-хоста);
   - пропусти индексы, которые уже залиты инструментом Fill: если `sk.hasFills()`, исключи
     `sk.filledRegionsCached()` (чтобы не было двойной заливки);
   - все грани одного скетча — одним вызовом `renderFacesFill(faces, color, alpha, view, proj)`;
   - обход скетчей — точно как в блоке Fill tool (видимые, кроме активного; потом активный).
3. Не трогай подсветку выбранных/наведённых регионов (`highlightRegion`) — она рисуется поверх и
   остаётся ярче.

Проверь в `Sketch.h`, что `drawnRegions`, `hasFills`, `filledRegionsCached`, `regionsCached`,
`buildRegions` существуют с такими сигнатурами; в `SketchTool.h` — `isPlacing()`.

## Самопроверка
- Перечитай блок целиком; сравни построчно с блоком Fill tool — та же схема кэша/воркера.
- В отчёте — какие сигнатуры проверил и где.

## Критерии приёмки (куратор, на планшете)
- Нарисовать прямоугольник → внутри бледная заливка; незамкнутая ломаная — без заливки.
- Выбранный регион по-прежнему ярко-жёлтый поверх.
- Во время рисования линии нет подтормаживаний.
